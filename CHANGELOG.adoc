== Changelog

All notable changes to this project will be documented in this file.

The format is based on https://keepachangelog.com/en/1.1.0/[Keep a
Changelog], and this project adheres to

=== [Unreleased]

==== Added

* Repository minted from the RSR template (`just repo-init rust-cli`): a
  placeholder crate that reports its package name and version, with its tests
  and the template's CI and metadata. There is no Chapel functionality yet.
* `Cargo.lock` committed, and `Cargo.toml` and `Cargo.lock` allowed at the
  repository root.

==== Changed

* The direct `panic-attack assail` scan in `static-analysis-gate.yml` is
  replaced by panicbot, which is now enrolled in `.gitbot-fleet/enrolment.json`
  (owner ruling 2026-11-12). The old assail evidence is an explicit `not_run`
  envelope.
* The proven suite reports the Zig FFI lane as not applicable when
  `src/interface/ffi` is absent, instead of failing on the missing directory.

The template's own release history is kept in `hyperpolymath/rsr-template-repo`.
